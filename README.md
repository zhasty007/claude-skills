# claude-skills
<p>A working set of Claude skills I use across legal practice, consulting work, and long-form writing. The collection includes domain-specific skills for Connecticut personal injury law and DeFi analysis, plus general-purpose tools for meeting minutes, slide narratives, market sizing, competitive teardowns, and a humanizer pass for stripping AI tells out of generated prose. Each folder contains a <code>SKILL.md</code> with trigger conditions and workflow instructions Claude follows automatically. Drop the folders into your skills directory and Claude will invoke them on relevant requests without extra prompting.</p>
